### 💼 Enterprise Project Experience

#### Western Union – Digital Money Transfer Platform

| Attribute | Details |
| :--- | :--- |
| **Client** | Western Union |
| **Organization** | LTI (LTIMindtree) |
| **Domain** | Banking, Financial Services and Insurance (BFSI) / FinTech |
| **Role** | Senior Quality Analyst / SDET (`5.5+ Years Experience`) |
| **Sprint Scope** | Australia (AU) & Canada (CA) Digital Money Transfer Releases |

**Project Description**  
Worked on Western Union's digital money transfer platform, enabling customers to execute international money transfers across web and mobile applications. The platform supports customer registration, multi-factor authentication, receiver management, foreign currency exchange, dynamic transaction fee calculation, multiple payment methods, and transfer history. As part of the **Australia (AU) and Canada (CA)** sprint team, led **Playwright & TypeScript** UI/API automation, end-to-end functional testing, regression testing, and business requirement validation to ensure financial accuracy and a seamless customer experience.

**Roles & Responsibilities**
- Analyzed business requirements, user stories, and acceptance criteria to identify automation candidates, functional testing scenarios, edge cases, and potential release risks.
- Architected and maintained modular **Playwright & TypeScript** E2E automation scripts using the **Page Object Model (POM)** for Send Money journeys (SMO), authentication, receiver management journeys and End-user journeys  .
- Prepared and executed comprehensive test scenarios and test cases covering functional, UI, negative, and end-to-end testing across web and mobile applications.
- Tested **Send Money (SMO)** functionality, including currency selection, live exchange rate calculation, transfer fee calculation, promotional codes, and transaction estimation details.
- Validated **My Receivers** and **Transfer History** features, including beneficiary management, search filters, sorting, chronological transaction ordering, and **Quick Resend** flows.
- Automated and executed REST API validations using **Playwright (`APIRequestContext`)** and **Postman** to verify request/response payloads, HTTP status codes, response headers, and business rule validations.
- Validated customer authentication workflows, including login, OTP verification, MFA, Remember Me, biometric login, and password reset scenarios.
- Executed manual and automated cross-browser and cross-platform regression suites across desktop and mobile viewports using **BrowserStack**.
- Logged, tracked, and triaged defects using **Jira**, analyzing backend application logs in **Splunk** and collaborating with developers and product owners through root-cause resolution and retesting.
- Maintained test cases, automation execution results, and audit-ready artifacts in **TestRail** and **Zephyr**, while publishing daily QA status reports, defect summaries, and release sign-off updates in Agile/Scrum ceremonies.

**Tools & Technologies:** `Playwright` · `TypeScript` · `Postman` · `REST APIs` · `BrowserStack` · `Jira` · `TestRail` · `Zephyr` · `Splunk` · `Agile/Scrum`
